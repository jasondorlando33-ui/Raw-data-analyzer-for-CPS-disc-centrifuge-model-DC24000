Raw data analyzer CPS disc centrifuge model DC24000

===================================================

\-This program will generate an excel file with descriptive statistics and raw data to reproduce the instrument display for all sample files provided.

\-The aim is to limit the need for manual data table construction and to provide raw data that allows for flexible graphing.





**Running the program:**

**--------------------**

\-This program .exe was added to a folder on the P drive (P:\\RandD\\CPS disc centrifuge model DC24000 Raw data analyzer) but can be copied to another location

\-Prior to running the program the .dat files for the samples of interest need to be added to the folder with the program

\-Starting the program will open a terminal which after \~30s will display the main menu of the program prompting you to \[1] Run data analyzer program or \[2] close the program.

\-Running the program will save an excel file to the folder that has a sheet with a descriptive statistics table on all of the samples and a sheet with the raw data.

\-The program will then revert to the menu for repeat calculations if needed.



**Things to remember:**

**-------------------**

\-Always remove the generated excel file as repeat runs will save over it.

\-Be sure to remove your data from the folder for following runs as to not add them to your next table.

\-Having the excel file or any of the .dat files open will cause the program to crash. Closing the file and rerunning the program will fix that issue.
